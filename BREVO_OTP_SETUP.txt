TradeBook OTP setup

1. Frontend endpoint:
https://tradebook-otp.tradebook2009.workers.dev/send-otp

2. Cloudflare Worker:
Deploy worker.js from this package to the Worker named tradebook-otp.

3. Required Cloudflare secret:
BREVO_API_KEY = your Brevo API key

4. Brevo sender:
tradebook2009@gmail.com must be a verified sender in Brevo.

5. GitHub Pages:
The allowed frontend origin is:
https://tradebook2009.github.io

Important:
The frontend app.js sends JSON in this form:
{ "to": "user@example.com", "otp": "123456" }

The Cloudflare worker.js in this package is written to accept exactly that request.
Do not replace it with a Worker that expects only { "email": ... } or generates a different OTP contract.


Settings OTP is also enabled for:
- Change Password: current password -> OTP -> update password
- Delete Account: current password -> OTP -> existing email verification -> delete account
