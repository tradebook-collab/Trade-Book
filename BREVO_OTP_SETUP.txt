TRADEBOOK - CLOUDFLARE OTP WORKER SETUP

1. Deploy worker.js as a Cloudflare Worker.

2. In the Worker settings, add these encrypted Secrets:
   BREVO_API_KEY = your Brevo API key
   SENDER_EMAIL = your verified Brevo sender email

3. Optional Worker variable:
   SENDER_NAME = TradeBook

4. The Worker URL is already set in brevo-config.js as:
   https://tradebook-otp.tradebook2009.workers.dev/send-otp
   Change it only if your Worker URL is different.

5. Deploy the TradeBook files to GitHub Pages.

6. Open the Worker root URL. It should return JSON similar to:
   {"success":true,"message":"Trade Book OTP Worker is online"}

7. Test TradeBook Settings -> Forgot Password -> Send OTP.

IMPORTANT:
- Never put BREVO_API_KEY inside app.js, brevo-config.js, index.html, or GitHub.
- The browser sends only the email address and generated 6-digit OTP to the Worker.
- The Worker keeps the Brevo API key private.
- OTP expires after 2 minutes in the TradeBook UI.
- Resend Code invalidates the previous OTP in the current browser session.
- IndexedDB/trading data logic is unchanged.
