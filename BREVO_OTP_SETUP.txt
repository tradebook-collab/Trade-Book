TRADEBOOK - BREVO OTP SETUP

1. Open brevo-config.js.
2. Set apiKey to your Brevo API key.
3. Set senderEmail to the VERIFIED sender email in Brevo.
4. Deploy the files.

IMPORTANT SECURITY NOTE
The Brevo API documentation says API keys are secrets and should not be exposed in client-side code or committed to public repositories. This GitHub Pages version therefore ships with placeholders only. A production-safe setup needs a server-side endpoint (for example a Cloud Function/server) that stores BREVO_API_KEY privately and sends the OTP.

OTP behavior remains: 6 digits, 2-minute expiry, Resend Code invalidates the previous code, then correct OTP opens New Password. IndexedDB/trading data logic is unchanged.
